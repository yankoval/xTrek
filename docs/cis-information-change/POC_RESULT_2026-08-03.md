# Результат промышленного PoC корректировки дат КИЗ

Дата: 2026-08-03  
Товарная группа: `chemistry`  
Контуры: тестовое хранилище xTrek + промышленный True API  
Итог: обе операции и полный возврат исходных дат успешны

## Тестовая партия

- количество КИЗ: 4;
- тип упаковки: `UNIT`;
- исходный и финальный статус: `INTRODUCED`;
- исходная дата производства: `2026-06-01`;
- исходная дата окончания срока годности: `2029-06-01`.

Полные коды были прочитаны универсальной командой из объекта `kodes` тестового
storage. Задачи, квитанции и статусы сохранялись только в тестовом контуре.

## Обнаруженная и исправленная ошибка формата

Первый документ даты производства был принят методом создания документов, но
получил `CHECKED_NOT_OK`: для каждого КИЗ вернулась ошибка `03` о недопустимом
формате поля «Код идентификации».

Причина: источник `kodes` содержит полный код маркировки с криптохвостом после
ASCII GS, а `CIS_INFORMATION_CHANGE` принимает КИ без криптохвоста. Команда
исправлена: все входные полные коды нормализуются канонической функцией
`cut_crypto_tail`; дубликаты проверяются после нормализации. Отправка вручную
сформированной задачи с криптохвостом теперь отклоняется локальной валидацией.

## Успешная проверка

| Операция | Статус | Проверенное значение |
|---|---|---|
| Временная дата производства | `CHECKED_OK` | `2026-06-02` |
| Временный срок годности | `CHECKED_OK` | `2029-06-02` |
| Возврат даты производства | `CHECKED_OK` | `2026-06-01` |
| Возврат срока годности | `CHECKED_OK` | `2029-06-01` |

После каждого успешного документа значения проверялись независимым запросом
`POST /api/v3/true-api/cises/info`. Финальная проверка подтвердила возврат обеих
исходных дат у всех четырёх КИЗ. По требованию API дата производства и срок
годности во всех случаях передавались отдельными документами.

Подробные внутренние идентификаторы и адреса артефактов намеренно не включены
в публичную документацию.
