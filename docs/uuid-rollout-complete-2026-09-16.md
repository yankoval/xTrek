# Завершение перехода True API на UUID

16.09.2026 Фитокосметик (7733154124) переключён на UUID на VPS и в активном
клиенте Mac. Смарткосметик (9723161905) и Глобал Био (9718180660) уже используют
UUID. Все три организации читают True API и отдельные токены СУЗ из `tokens-v2.json`.

Сначала UUID Фито выпущен через штатный SignJS под общей блокировкой мастера,
проверен и опубликован; затем атомарно изменена политика только этого ИНН.
Исходные конфигурации и реестр сохранены в приватных резервных копиях.
Значения токенов, рабочие конфигурации и производственные артефакты в Git не включены.

Проверки после переключения:

- True API: проверка баланса и `product/info` успешна, HTTP 200.
- Все шесть сочетаний ИНН/назначение проверены; для СУЗ использован подписанный ping.
- На Mac подтверждён выбор того же UUID Фито; True API и Национальный каталог — HTTP 200.
- Обычный цикл мастера в 14:10 МСК: актуальны=6, обновлены=0, ошибки=0.
- Celery и таймер мастера активны; перезапуск не потребовался.
- Полный локальный прогон: 320 тестов и 14 вложенных проверок прошли.
  Команда: `python tools/run_token_regressions.py tests/`; реальные сетевые соединения запрещены.

Политика действующих установок явно задаёт UUID для всех трёх ИНН.
Значение по умолчанию в действующей конфигурации оставлено JWT: переключение
затрагивало только Фито. Новый пример конфигурации использует v2 и UUID по умолчанию;
его нельзя копировать поверх рабочих настроек и секретов.

После переключения мастер больше не обновляет JWT этих трёх организаций.
Сохранённые JWT не являются автоматическим fallback. Для отката сначала проверить
действительность JWT, затем вернуть только политику нужного ИНН на VPS и клиенте.
Нельзя заменять весь реестр старой резервной копией: это затрёт последующие ротации СУЗ.

Наблюдение 15–16 сентября подтвердило плановые ротации обоих назначений.
15 сентября остановка VPS привела к пропущенному обновлению; после восстановления
четыре записи опубликованы на 11–50 секунд позже срока прежних токенов.
Последующие проверенные циклы прошли без ошибок. Суточное наблюдение продолжается
до 16 сентября 17:20 МСК; этот документ не заменяет его окончательный итог.

Известные отдельные проблемы: повторы агрегации двух виртуальных тестовых заказов
в Celery при отсутствии отчёта оборудования; четыре старых сообщения подписи
тестового ИНН; дефекты cf из issue #13. Они не исправлялись переключением токенов.
