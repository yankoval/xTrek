# Внешняя обработка «Выгрузка эмиссии»

Исходники и сборка `dist/ВыгрузкаЭмиссии.epf` (ui-v7) для 1С 8.3.27.2214.
Сборка, нативный запуск Windows и ui-v7 в 1С проверены: окна CMD не появляются,
запись, чтение, идентичный повтор и отказ конфликтующей записи проходят.
Конфигурация базы не изменяется. Контрольные суммы модулей и EPF — `dist/build.json`.
Результаты проверки от 22.10.2026 — [dist/ui-v7-verification.json](dist/ui-v7-verification.json).

Стартовая вкладка показывает последние 200 эмиссий за выбранный период, новые сверху.
Доступны GTIN, артикул, наименование, даты серии и открытие документа. Ссылка
«Номенклатура» доступна через стандартное изменение формы. Команды размещены в строку.

1. На вкладке настроек выбрать один транспорт и сохранить настройки пользователя.
2. Указать общую папку журнала, доступную службе 1С для всех пользователей.
3. Выделить строки либо выбрать все невыгруженные; нажать «Проверить».
4. Проверить и подтвердить даты; нажать «Выгрузить выделенные».

Транспорты:
- `local`: существующая папка 1CExchange на сервере 1С. Лимит действующего uploader — 1 МиБ.
- `aws`: AWS CLI на Windows-клиенте под текущим пользователем (например, project).
  Указать его именованный профиль, бакет и префикс. Профиль службы и права администратора
  не нужны. AWS запускается через `WScript.Shell.Run` со скрытым окном и ожиданием
  завершения; код возврата проверяется как прежде. Консольные окна не открываются.
  1С может запросить отдельное разрешение на использование COM-объекта.
  CLI должен поддерживать `s3api put-object --if-none-match`.
- `function`: HTTPS-адрес существующей облачной функции и общий префикс.

Секреты AWS остаются в профиле CLI. Все транспорты запрещают перезапись другого
содержимого; идентичный повтор допустим. Сначала публикуются коды, затем задание.
Одна эмиссия должна содержать один полностью полученный блок, не более 30 000 кодов.
Имена: orderId СУЗ для кодов, UUID документа 1С для задания.

Отметки выгрузки общие, хранятся в файловом журнале и не требуют запросов к S3 при
открытии списка. Они различаются по назначению транспорта. «Выгружено» означает
доставку файлов, а не подтверждённый ввод в оборот. Смена данных или назначения
требует повторной проверки и подтверждения дат.

Для пересборки через Конфигуратор:

```text
1cv8.exe DESIGNER /S"<сервер>/<база>" /N"<пользователь>" /LoadExternalDataProcessorOrReportFromFiles "<каталог>\ВыгрузкаЭмиссии.xml" "<каталог>\ВыгрузкаЭмиссии.epf" /Out"<каталог>\build.log"
```

После изменения модулей пересобрать EPF и обновить контрольные суммы. Открытие внешней
обработки и запуск приложения могут требовать отдельных разрешений пользователя 1С.
Для передачи сборок использовать перенаправленную по RDP папку Downloads либо
Desktop\Codex пользователя project; корень диска F не использовать.

Базовая ui-v6 проверена пользователем: открытие документов, товарные колонки, даты,
клиентская AWS-запись/чтение, идентичный повтор и отказ конфликтующей записи.
Через неё выгружены реальные тестовые эмиссии UNIT/SET для успешного изолированного прогона.
Кнопка проверки тестового AWS предназначена для диагностического тестового префикса;
настройки рабочей выгрузки она не меняет.
